# Invitación web de bautizo y primer año

Esta carpeta contiene una página estática lista para publicar gratis con GitHub Pages.

## Archivos
- `index.html`: contenido de la invitación.
- `styles.css`: diseño adaptable a celulares y computadoras.
- `script.js`: cuenta regresiva para el 19 de diciembre de 2026.
- `assets/invitacion.mp4`: video que compartiste.

## Publicarla gratis con GitHub Pages
1. Entra a https://github.com e inicia sesión.
2. Crea un repositorio nuevo. Puedes llamarlo `invitacion-bautizo`.
3. Sube **todos** los archivos y carpetas de este proyecto, conservando la estructura.
4. En el repositorio entra a **Settings → Pages**.
5. En “Build and deployment”, selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/ (root)`, luego pulsa **Save**.
7. Espera unos minutos. GitHub mostrará la dirección pública de la invitación en esa misma sección.

## Cómo actualizar el video después
Reemplaza `assets/invitacion.mp4` por el nuevo video usando exactamente el mismo nombre y ruta, y guarda los cambios en GitHub. Si el navegador conserva el video anterior en caché, abre el sitio en una ventana privada o actualiza la página.

## Personalizar texto o diseño
- Cambia los textos en `index.html`.
- Cambia colores, tamaños y estilo en `styles.css`.
- Si cambia la fecha, actualiza el texto de la fecha en `index.html` y la fecha en `script.js`.

No hay formulario de confirmación de asistencia. Los botones abren las dos ubicaciones de Google Maps que compartiste.
